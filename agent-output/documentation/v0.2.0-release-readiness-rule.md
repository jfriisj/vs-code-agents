# v0.2.0 Release Readiness Rule

## Rule: Cross-Tool Consistency Anchor
A release candidate for v0.2.0 (or subsequent versions) shall not be considered "Ready for UAT" unless the following cross-tool evidence is documented in the Implementation artifact:

1. **Strategic Sync**: The Roadmap H1 status for the target Epic explicitly matches the "Active Release Tracker" table status.
2. **Agile Verification**: The corresponding Planka Card contains a completed "Acceptance Criteria" checklist that mirrors the Roadmap criteria.
3. **Graph Integrity**: The Obsidian workflow note (WF-ID) passes the zero-dependency verifier script.
4. **Relational Trace**: The Memory graph contains a verified relation chain.

## Enforcement
This rule is enforced by the QA agent during Milestone 3 of any Plan. Any failure in consistency constitutes a QA Failed verdict, regardless of code quality.
